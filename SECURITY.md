# Security model

Invented authorized data, trusted interpreter/source and owned ordinary files.
Data never executed/fetched. Pure core has no I/O/network/subprocess/dynamic
imports. CLI reads bounded local regular input, creates exclusive fresh output.
No telemetry, registry, cloud inference or automatic downloads.

Exact types before hooks. Strict UTF8, lexical depth/numeric token, duplicate
keys, native occurrence/depth/text/count and version caps precede modeling.
Incomplete reports have no scenario projection. CONTRACT.md freezes priority.
Logical bounds are not hard RSS/runtime containment or malware isolation.
Concurrent native mutation, hostile reparse paths/racing replacement, output
atomicity/durability and real package solving are unsupported. Failures can leave
partial bytes. Model observations cannot certify security/compatibility/existence.

No secrets, actual samples or private package evidence in fixtures/shared notes.
Repository/publication/hosted security configuration not authorized. This policy
does not grant external messaging authority.
